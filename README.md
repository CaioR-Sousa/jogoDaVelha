
# 🎮 Jogo da Velha

Um projeto desenvolvido com **HTML, CSS e JavaScript** que recria o clássico **Jogo da Velha (Tic-Tac-Toe)** de forma interativa e responsiva.

O objetivo deste projeto foi praticar manipulação do DOM, lógica de programação, eventos, controle de estado e organização do código em JavaScript puro.

---

# ✨ Funcionalidades

* ✅ Partida entre dois jogadores
* ✅ Alternância automática entre X e O
* ✅ Verificação de vitória
* ✅ Verificação de empate
* ✅ Destaque para o vencedor
* ✅ Reiniciar partida
* ✅ Interface responsiva

---

# 🛠️ Tecnologias Utilizadas

* HTML5
* CSS3
* JavaScript (ES6)

---

# 📚 Conceitos Praticados

Durante o desenvolvimento deste projeto foram praticados conceitos como:

* Manipulação do DOM
* Eventos (`addEventListener`)
* Arrays
* Condicionais
* Funções
* Laços de repetição
* Controle de estado do jogo
* Organização do código
* Responsividade

---

# 🎯 Objetivos do Projeto

Este projeto foi criado com a finalidade de reforçar conhecimentos em JavaScript, principalmente na construção de aplicações interativas sem utilização de frameworks.

Também serviu como prática para:

* Pensamento lógico
* Estruturação de funções
* Validação de regras do jogo
* Manipulação dinâmica da interface
